# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja gentil e respeitoso. Este repositório é uma homenagem a uma pessoa
real. Comentários ofensivos, assédio, ou qualquer uso das fotos e dados pessoais
das pessoas retratadas não são tolerados.

Casos de comportamento inadequado podem ser reportados de forma privada pelo
[aviso de segurança do GitHub](https://github.com/GabrielDS02/ela-simplesmente-incrivel/security/advisories/new)
ou abrindo uma issue. Toda denúncia será analisada com cuidado e sigilo.
