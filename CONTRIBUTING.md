# Como contribuir

Este é um projeto pessoal (uma homenagem), então o conteúdo dele não muda por
contribuições externas. Mas sugestões e correções de código são bem-vindas! 💗

## Reportar um problema
Abra uma [issue](https://github.com/GabrielDS02/ela-simplesmente-incrivel/issues/new/choose)
dizendo o que aconteceu, em qual aparelho/navegador e, se possível, com um print.

## Sugerir uma melhoria no código
1. Faça um fork e crie uma branch: `git checkout -b fix/minha-correcao`.
2. Rode o site localmente: `python -m http.server 8080`.
3. Teste no celular (ou no modo responsivo do navegador) e no computador.
4. Siga o estilo do projeto (`.editorconfig`): 2 espaços em HTML/CSS/JS, 4 em Python, comentários em português.
5. Use mensagens de commit no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/) (`feat:`, `fix:`, `docs:`…).
6. Abra o Pull Request explicando o que mudou.

## O que não aceitamos
- Mudanças nas fotos, textos e mensagens pessoais.
- Dependências pesadas ou etapas de build: o site é HTML, CSS e JS puros de propósito.

Quer a sua própria versão? Faça um fork e troque as fotos e os textos pelos seus. Veja o [README](README.md).
